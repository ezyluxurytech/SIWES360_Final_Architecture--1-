# SIWES360

**Student Industrial Training Management & Monitoring System**

A practical Computer Science / SIWES project for managing student industrial training from placement through attendance, digital logbook, weekly reporting, supervision and evaluation.

## Final technology stack

- HTML5
- CSS3
- Vanilla JavaScript
- PHP 8+
- MySQL
- PDO
- XAMPP / Apache

## Important

This final version uses the PHP/MySQL application generated by Google AI Studio as the base, but removes the conflicting React/TypeScript mock application and aligns the PHP application with the actual `siwes360` database schema.

The database already created in phpMyAdmin is the source of truth.

### Do not import

`database/siwes360_reference.sql` is a schema reference/backup only. Do not import it over a working database containing your project data.

Read `ARCHITECTURE.md` before modifying the project.

The central relationship is:

**Student → Placement → Attendance / Activities / Weekly Reports / Evaluations**

## Local setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the `siwes360` folder into `C:/xampp/htdocs/`.
4. Make sure your existing MySQL database is named `siwes360`.
5. Open:

`http://localhost/siwes360/`

6. Log in using an account already stored in your database.

## Important development rule

Do not add React, TypeScript, Vite, localStorage authentication, mock data or another database architecture unless the project requirements are deliberately changed.
